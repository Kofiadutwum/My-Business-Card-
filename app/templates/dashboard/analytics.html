What is and is not recorded

Each opening records the date, how the visitor arrived, and a one-way fingerprint used only to tell a repeat visit from a new one. No names, no phone numbers, and no stored IP addresses — under Ghana's Data Protection Act an IP address is personal data, so it is hashed on arrival and the original is never written down.
